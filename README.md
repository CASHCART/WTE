## Run requirements

- Servlet questions use `javax.servlet` and require a compatible Servlet container such as Tomcat 9. Each servlet question folder includes the relevant `WEB-INF/web.xml` when it uses descriptor mapping.
- JDBC programs use Oracle XE settings and credentials from the existing setup. Add the Oracle JDBC driver to the classpath or web application as required.
- BookServlet and the JSP run `select * from books` and expect the columns Title, Author, Edition, and Price in that order.
- XML programs should be validated with their accompanying DTD or XSD files.
